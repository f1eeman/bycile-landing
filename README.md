# Chopper Bikeshop — магазин велосипедов-чопперов

Статический магазин на три страницы, свёрстанный по картинкам макета: главная,
каталог велосипедов, карточка товара. Плюс страница политики конфиденциальности, на
которую ведёт подвал. Astro, статическая сборка, Yarn.

## Страницы

- `/` — промо, велосипеды, мастерская, запчасти и аксессуары, форма вступления в
  клуб;
- `/catalog/` — строка управления, фильтр, сетка из девяти велосипедов, пагинация;
- `/product/` — седло Steed G67: фото с окном «Приблизить», описание, вкладки,
  «С этим товаром смотрят»;
- `/privacy/` — политика конфиденциальности, пока без текста.

## Макет

Файла Figma нет: макет — три кадра JPEG шириной 1366 и текстовый файл,
`docs/mockup/`. Числа сняты с пикселей скриптом, тексты — из `text.txt`. Метод —
`docs/adr/0006-jpeg-mockup.md`, карта секций — `docs/mockup.md`. Узких кадров нет: раскладки телефона и
планшета выведены из десктопных замеров, вывод — `docs/adr/0008-responsive-steps.md`.

## Команды

```
yarn dev            # дев-сервер на 4321
yarn build          # astro check && astro build
yarn preview        # просмотр сборки
yarn lint           # ESLint
yarn lint:styles    # Stylelint
yarn format         # Prettier
yarn test:browser   # Playwright: собирает и поднимает просмотр на 4331
```

**Только Yarn.** `npm install` при наличии `yarn.lock` перепишет его под себя и
сломает установку у коллег на других платформах.

Гарнитуры — Roboto Serif и Roboto — лежат в `src/assets/fonts/` и подключаются
локально через `astro:assets`: сеть для сборки не нужна. Почему не гарнитура
макета — `docs/adr/0007-typefaces.md`.

## Что перенесено и что придумано

С картинок перенесено всё, что на них нарисовано, на ширине 1366; тексты — из
`text.txt`, где он с картинкой расходится. Придуманы, потому что макет молчит:
раскладки телефона и планшета, подтверждение после отправки формы клуба,
содержимое вкладок, кроме «Отзывов», вид каталога «списком», окно «Приблизить»,
адреса пунктов меню без своих страниц, фавикон и превью для соцсетей, заголовки и
описания страниц. Полный перечень с ценой каждого решения — PRD, раздел «Что
придумано, потому что макет молчит».

## Чего не хватает до прода

- **Домен.** `site` в `astro.config.mjs` и адрес карты сайта в `public/robots.txt`
  — заглушка `https://example.invalid`. Настоящий домен заменяет оба места
  (`docs/deploy.md`).
- **Данные юрлица.** Название, телефон и почта организации в `seo.astro` —
  заведомо нерабочие заглушки (`docs/adr/0005-seo-metadata-and-indexing.md`).
- **Текст политики конфиденциальности.** Страница есть, текста нет.
- **Отправка заявки.** Форма клуба проверяет поля и показывает подтверждение, но
  ничего не отправляет: точка врезки запроса одна — `send` в
  `src/scripts/request-form.ts`.
- **Логика магазина.** Корзина, фильтр, сортировка, «Показывать по», страницы
  каталога, поиск и личный кабинет — вёрстка без поведения (PRD, «Границы»).
- **Адреса соцсетей.** Ссылки ведут на главные страницы сетей.
